# 役割分担

| 層 | 担当 | 持つ権限 | やらないこと |
|---|---|---|---|
| 上層: Claude in Chrome | ComfyUI の画面操作、ワークフロー作成、パラメータ調整、エラー内容の読み取り | 開いているページの操作、ページへのコード送信 | 環境の変更、ComfyUI 以外のタブの操作 |
| 人間 | 依頼の確認と中継、外部情報・導入の承認 | すべて | 内容を読まずに転送すること |
| 下層: Claude Code | 環境構築、カスタムノード導入、ファイル・スクリプト作成 | ローカルのファイルとシェル | 上層からの依頼の無確認実行 |

## 人間が中継する理由

上層は外部の文章(他人のワークフロー、ノードの README など)を読むことがあり、そこに含まれる指示に影響される可能性がある。上層と下層を直接つなぐと、その影響が下層の強い権限にそのまま届く。人間が依頼を読んで中継することで、この経路に確認の段階を入れる。

## 運用の記録

実際の運用では、ローカルの PC に変更を加える作業はほぼ下層、それ以外の実作業(ワークフロー作成、生成、自動試行、記録メモ)はほぼ上層が担当した。下絵は人間がお絵描きソフトで描いた。ただし上層も、ComfyUI のアップロード機能を通じて、加工した画像を入力フォルダに書き込んでいた。上層は「ローカルのファイルに触れない」わけではなく、ComfyUI が許す範囲では書き込める。2階建ては最初から設計したものではなく、上層の手が届かない作業が出たときに下層を併用したことから生まれた。
