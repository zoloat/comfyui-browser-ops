# 先行例の調査

調査日: 2026-10-20
調べた範囲: X のリアルタイム検索、Zenn、note(各数回)

## 結果

- ブラウザ操作を Claude にさせること自体は新しくない。Claude in Chrome は公式の拡張機能で、英語・ロシア語・日本語で利用例が多数ある。
- ComfyUI との組み合わせでは、タイの投稿者(2026-01-04)の例がある。Claude Code に Claude in Chrome をつなぎ、ComfyUI のフロー作成、サーバーとエンドポイント作成、スキル化まで行っていた。
- Zenn には、Claude Code in Chrome の可能性とセキュリティ面をまとめた記事が1件(ComfyUI は扱っていない)。
- note には、Claude Code から Claude in Chrome を呼び出す連携方法の記事(手順中心)。
- 日本語で、2階建ての構造と ComfyUI 運用を具体的に書いた例は、今回の範囲では見当たらなかった。

## このリポジトリの立ち位置

- 「世界初」ではなく、「日本語で具体的に書いた例が少ない」。
