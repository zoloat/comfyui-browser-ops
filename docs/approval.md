# カスタムノード導入の承認

カスタムノードは任意のコードを実行する。導入前に、Claude が次の項目を提示し、人間が承認してから実行する。

## 提示する項目

| 項目 | 内容 |
|---|---|
| URL | リポジトリの URL |
| 理由 | どのノードが足りず、なぜ必要か |
| 公式レジストリ | ComfyUI Registry への掲載の有無 |
| 作者 | アカウント名と、他の公開リポジトリの有無 |
| 更新日 | 最終コミット日 |
| スター数 | GitHub のスター数 |
| README の要約 | 何をするノードか、依存パッケージ |

## 導入後の確認

- `requirements.txt` の中身(見慣れないパッケージ、バージョン指定のない取得元)
- `install.py` など、導入時・起動時に実行されるスクリプト
- 確認は人間が行う。Claude は要約を出してよいが、判断は人間。
