# 依頼書(上層 → 人間 → 下層)

上層(Claude in Chrome)が書き、人間が確認してから下層(Claude Code)に渡す。

## 上層が記入

- 依頼内容:
- 理由(どの画面で何が起きたか):
- 出典 URL(参考にした外部ページ。なければ「なし」):
- 変更されるもの(ノード、パッケージ、ファイル):

## 人間が記入

- [ ] 依頼内容を読み、意図と合っている
- [ ] 出典 URL を自分で開いて確認した
- [ ] 外部の文章をそのまま貼り付けていない(必要なら自分の言葉で書き直した)
- [ ] カスタムノードの場合、[approval.md](../docs/approval.md) の項目を確認した
- 下層に渡す文面:
